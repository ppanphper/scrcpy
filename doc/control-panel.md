# 控制台

控制台是一个本地网页界面，用来把常见的 `scrcpy` 和 `adb` 操作做成按钮。

它不会替换官方 `scrcpy` 客户端，也不会重写 scrcpy 协议。控制台只负责启动
已安装的 `scrcpy` 可执行文件，并通过 `adb` 发送常用 Android 控制命令。

这种方式的目标是：保留官方 scrcpy 的稳定性和性能更新，同时减少记命令和记
快捷键的负担。

## 形态

当前版本是浏览器本地控制台：

```text
浏览器界面 -> 本机 Python 服务 -> scrcpy / adb
```

它和 QtScrcpy 的原生 Qt 桌面窗口不是同一种实现。QtScrcpy 把客户端、渲染、
连接管理和控制界面做成了一个 Qt 应用；本控制台则是官方 scrcpy 的外层
launcher/controller。

## 依赖

先安装 `scrcpy` 和 `adb`，并确认两个命令都能在 `PATH` 中找到：

```bash
scrcpy --version
adb version
```

macOS 使用 Homebrew：

```bash
brew install scrcpy
brew install --cask android-platform-tools
```

## 启动

在仓库根目录运行：

```bash
python3 tools/scrcpy-control-panel.py
```

默认会打开：

```text
http://127.0.0.1:27190/
```

页面左上角会显示当前后端控制台版本号。版本号来自正在运行的 Python 服务；更新
代码后如果版本没有变化，请关闭并重新启动控制台，再刷新页面。

如果不想自动打开浏览器：

```bash
python3 tools/scrcpy-control-panel.py --no-open
```

从手机下载的文件默认保存到 `~/Downloads/scrcpy-control-panel`，可以用参数改到别处：

```bash
python3 tools/scrcpy-control-panel.py --download-dir ~/Desktop/phone-files
```

macOS 也可以双击：

```text
tools/Scrcpy Control Panel.app
```

这个 app 只是快速启动器，实际仍运行仓库里的 `tools/scrcpy-control-panel.py`。
可以把它复制到 `/Applications`，但不要从仓库里移动走；复制后它会优先查找
`~/ai-code/scrcpy/tools/scrcpy-control-panel.py`。如果仓库放在其它位置，可以设置
`SCRCPY_CONTROL_PANEL_SCRIPT` 指向脚本路径。

## 推荐流程

控制台按 4 步引导操作，并会自动禁用当前阶段不该点击的按钮：

1. 检测设备：刷新 ADB 设备列表。打开页面、刷新和重启 ADB 时，如果已保存的无线地址
   不在列表中或已离线，控制台会自动执行一次 `adb connect`；重启 ADB 前已连接的无线
   设备也会在重启后自动连回。手动断开的地址不会被自动连回，直到再次手动连接。
2. 建立连接：USB 设备授权后可直接使用；也可以填写无线地址并点击“无线连接”。
   无线连接会先直接连接目标地址并等待设备进入可用状态；如果连接失败，控制台会
   自动重启本机 ADB server 并重试。
3. 启动投屏：检测到可用 USB 或无线 ADB 设备后，“启动 scrcpy”按钮才可点击。
   目标是无线设备但当前不在线时，会先自动连接，连接失败则直接提示原因，不启动 scrcpy。
4. 操控手机：scrcpy 启动后，返回、主页、音量、通知栏、截图等控制按钮才会显示。

## 已实现操作

- 刷新 ADB 设备，并自动连接已保存的无线地址
- 连接/断开无线 ADB 地址
- 重启本机 ADB 服务，并自动重连重启前的无线设备
- 为 USB 设备开启 TCP/IP 模式
- 启动/停止 `scrcpy`，启动按钮会在运行时切换为红色停止按钮
- 分组显示启动参数，默认展开常用项，其它视频、音频、窗口、设备行为、输入控制、录制、摄像头、虚拟显示和高级选项默认折叠
- 感知由控制台启动的 `scrcpy` 进程退出，并切换投屏状态
- 记录每次由控制台启动的 `scrcpy` 日志，便于排查启动失败或异常退出
- 返回、主页、多任务、电源、唤醒、熄屏
- 音量加、音量减、静音
- 展开通知栏、展开快捷设置、收起系统面板
- 保存截图到 `~/Pictures/scrcpy-control-panel`
- 通过 `adb shell input text` 输入纯 ASCII 文本
- 对当前设备执行一条 `adb shell` 命令
- 上传文件到手机：普通文件通过 `adb push` 推送到指定目录，APK 通过 `adb install -r` 直接安装
- 浏览手机目录并下载文件或整个目录到本机，底层使用 `adb shell ls` 和 `adb pull`

## 说明

控制台默认绑定 `127.0.0.1`，只有本机可以访问。

文本输入使用 Android 的 `adb shell input text`，只适合可靠输入纯 ASCII。
中文输入和复杂剪贴板同步仍建议使用 scrcpy 自带剪贴板快捷键。

如果手机 IP 变化，刷新设备或用新的 `ip:5555` 地址重新无线连接。

自动连接返回 `Connection refused` 时，通常是手机重启后无线 ADB 端口已关闭：
用 USB 连接手机后点击“开启 TCP/IP”，再改回无线连接。

关闭 `scrcpy` 投屏窗口不会自动断开 ADB。网页中的设备连接状态会继续显示
可用，但投屏状态会在轮询刷新后切换为未运行，操控按钮也会随之禁用。

点击网页右上角“关闭控制台”会停止由控制台启动的 `scrcpy` 进程，并关闭本地
网页服务。之后再次双击 app 或重新运行脚本即可启动。

控制台日志保存在 `~/Library/Logs/scrcpy-control-panel/`。如果 `scrcpy` 启动后
异常退出，网页日志区会显示对应日志文件路径和最近的错误输出。

## 文件传输

文件传输区在右侧“操控”面板下方，只要有可用的 ADB 设备就能使用，不要求先启动
scrcpy。

上传：点击虚线框选择文件，或把文件从访达拖进去，可以一次选多个。点击“上传到手机”
后，控制台会先把文件收到本机临时目录，再按下面的规则处理：

- 文件名以 `.apk` 结尾且勾选了“APK 直接安装”时，执行 `adb install -r`，安装完成后
  日志区会显示 `Success`；安装失败时会显示 `adb` 返回的失败原因，例如签名不一致。
- 其它文件（或取消勾选后的 APK）通过 `adb push` 推送到“手机目标目录”，默认是
  `/sdcard/Download`，保留原文件名。

一批文件里某个文件失败时，后面的文件不会继续上传，已成功的会从选择列表中移除，
方便只重传失败的文件。上传大文件时按钮会保持禁用，直到 `adb` 完成。

下载：在“手机路径”填写目录后点击“浏览目录”，列表里点击目录可进入，点击文件会把
路径填到输入框，双击文件直接下载。点击“下载到本机”会把该路径通过 `adb pull` 保存到
本机下载目录；路径是目录时会整个目录一起下载。本机已有同名文件时会自动加上 `-2`、
`-3` 这样的后缀，不会覆盖。

点击面板右上角“打开下载目录”会在访达中打开下载目录；如果本次会话刚下载过文件，
会直接定位到那个文件。

说明：

- `adb push` 会自动创建不存在的目标目录，但受 Android 存储权限限制，普通情况只能写
  `/sdcard` 下的路径。
- 目录浏览解析设备上 `ls -l` 的输出，已在 Android 10 的 toybox 上验证；更老的 toolbox
  格式也做了兼容，但未实际测试。
- 上传经过浏览器，单个文件上限 8 GB；临时文件在 `adb` 执行完成后立即删除。

## 锁屏密码黑屏

部分 Android 系统会把锁屏密码、图案、部分金融/隐私应用标记为安全界面。
这些界面可能在 scrcpy 中显示为黑屏，这是系统安全限制，并不适合在控制台中
绕过。

建议先在手机上完成解锁，再启动 scrcpy 或继续远程操控。控制台不会保存或
自动输入锁屏密码。
